# MIDNIGHT STEP

시티팝 퇴근길 리듬 워크 게임 (v45)

## 실행
- 로컬: `index.html` 더블클릭
- GitHub Pages: Settings → Pages → Branch `main` / root

## 구조
```
index.html              게임 코드 (0.4MB)
assets/data/*.js        이미지·스프라이트·컷신·강아지 데이터
assets/music/song*.js   스테이지 음악 10곡 (곡당 약 2.5MB)
```
폴더 구조를 그대로 유지해야 합니다 (`index.html`과 `assets/`가 같은 위치).
